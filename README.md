# Практическая работа №1

## Тема

HTML и базовая CSS-разметка. Семантическая структура страницы.

## Описание

Статическая адаптивная информационная страница по данным из `dataset`.

Использованы:
- HTML5;
- CSS3;
- семантические элементы `header`, `nav`, `main`, `section`, `article`, `footer`;
- Flexbox;
- медиазапрос;
- HTML-форма с встроенной валидацией;
- изображения из dataset.

## Структура проекта

```text
trpo-pr01-student/
├── index.html
├── README.md
├── .gitignore
├── css/
│   └── styles.css
├── images/
│   ├── logo.svg
│   └── cover.svg
└── data/
    ├── content.csv
    └── navigation.json
```

## Данные

Файл `data/content.csv` содержит 6 тем: HTML, CSS, Git, Forms, Accessibility и DevTools.

Файл `data/navigation.json` содержит пункты навигации:
- О курсе;
- Направления;
- Расписание;
- Регистрация.

## Запуск

1. Склонировать репозиторий.
2. Открыть файл `index.html` в браузере.

Дополнительные зависимости и установка npm не требуются.

## Проверка

Проверить:
- работу всех ссылок навигации;
- отображение 6 карточек;
- таблицу;
- валидацию формы;
- работу страницы на узком экране;
- переходы по клавише Tab.
